# Labs

Each lab in this folder corresponds to a lesson. The idea: you pick **one project** at the
start of the day and keep adding to it. By the end of lesson 06 you should have something
that actually runs, is yours, and demonstrates all the major SDK patterns.

**There is no starter code. There are no solutions.** The labs give you a goal, some
guardrails, and a few tips. You figure out the specifics — with your AI tools.

## How to use these

1. Start with [`00-pick-your-project.md`](./00-pick-your-project.md) right now.
2. After each lesson, open the matching lab and add that lesson's pattern to your project.
3. Use Claude Code or Cursor to do the actual coding. Your job is to **direct and review.**

## The one rule

> Build something you'd actually use or show someone.

A project that matters to you will teach you more than a contrived exercise. It will also
be harder — and that's the point. Your AI tools exist to help you get unstuck fast.
